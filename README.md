# CC Model Monitoring

## Overview

Credit card model monitoring project.

## Project Structure

```
CC_Model_Monitoring/
├── .github/
├── data/
├── docs/
├── input_files/
├── output_files/
├── scripts/
├── reports/
├── orchestration_2.Rmd
├── renv.lock
└── README.md
```

## Setup

1. Open `CC_Model_Monitoring.Rproj` in RStudio
2. Run `renv::restore()` to install dependencies
3. Knit `orchestration_2.Rmd` to execute the pipeline
